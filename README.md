# 🍽️ Restaurant Website

A modern, responsive, and visually appealing restaurant website developed using **HTML5 and CSS3**. This project is designed to provide visitors with an attractive online experience, featuring essential restaurant information, recipes, and contact details.

## 📌 Project Overview

The Restaurant Website is a front-end web development project that demonstrates the use of HTML and CSS to create a clean, user-friendly, and responsive website.

The website consists of four main pages, each designed to provide a smooth browsing experience.

## 📄 Website Pages

- **Home:** An attractive landing page introducing the restaurant.
- **About:** Information about the restaurant, its background, and its identity.
- **Recipes:** A collection of food recipes and culinary inspirations.
- **Contact:** Contact information and a section for visitors to get in touch.

## 🛠️ Technologies Used

- HTML5 – For website structure and content.
- CSS3 – For styling, layouts, and visual design.
- Visual Studio Code – For code development and editing.

## ✨ Key Features

- Modern and attractive user interface.
- Responsive and mobile-friendly design.
- Simple and user-friendly navigation.
- Structured multi-page layout.
- Clean HTML and CSS code.
- Visually appealing content and styling.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Open it in your preferred web browser.
5. Navigate through the different pages using the website menu.

Alternatively, use the **Live Server** extension in Visual Studio Code for a better development experience.
